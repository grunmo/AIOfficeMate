## 1. 产品概述

**AI办公助手** 是一款面向办公人群的智能文档管理系统，以"扫描件自动整理 + AI 智能命名分类 + 知识库沉淀"为核心能力，解决纸质文件电子化后归档混乱、检索困难、知识无法复用的痛点。

- **面向用户**：企业行政人员、财务人员、档案管理员、律师、医生等需要频繁处理纸质/电子文档归档的办公人群
- **产品形态**：桌面端智能办公应用（Windows / Mac 客户端，本地 Web UI），支持本地文件系统操作与 AI 辅助
- **核心价值**：自动化处理原本需要数小时人工完成的文件整理工作，文件检索效率提升 80% 以上，帮助中小企业低成本实现文档电子化与知识管理

## 2. 核心功能

### 2.1 用户角色

本产品第一版面向单机用户，暂不区分多角色。后续 SaaS 版本可扩展"管理员 / 普通用户"体系。

| 角色 | 注册方式 | 核心权限 |
| --- | --- | --- |
| 本地用户 | 无需注册，启动即用 | 浏览、上传、整理、搜索、配置 |
| （规划）在线用户 | 邮箱 / 手机注册 | 云端同步、多设备、团队共享 |

### 2.2 功能模块（MVP）

| 模块 | 主要能力 |
| --- | --- |
| ① 文件工作台 | 目录浏览、文件列表、拖拽上传、批量选择 |
| ② 扫描件处理 | 图片纠偏、旋转、裁切、亮度/对比度调整 |
| ③ AI 智能命名 | 基于 OCR + LLM 自动生成有意义的文件名 |
| ④ AI 智能分类 | 自动识别文件类型，归入建议的分类目录 |
| ⑤ 知识库工作区 | 按项目/部门建立知识库，全文检索，AI 问答 |
| ⑥ 系统设置 | 工作目录、模型 API Key、命名规则、外观主题 |

### 2.3 页面详情

| 页面 | 核心模块 | 功能描述 |
| --- | --- | --- |
| 首页 / 仪表盘 | 概览模块 | 今日整理统计、最近文件、快捷入口、AI 使用次数 |
| 文件工作台 | 文件浏览器 | 目录树、文件列表、网格/列表切换、拖拽上传、右键菜单 |
| 扫描件处理 | 图片编辑器 | 预览、纠偏、旋转、裁切、对比度、一键优化、批量处理 |
| AI 智能命名分类 | AI 面板 | 选择文件 → 预览 AI 建议 → 确认命名/分类 → 执行 |
| 知识库 | 知识空间 | 新建知识库、上传文档、标签、全文检索、AI 问答对话 |
| 系统设置 | 配置页 | 工作目录、LLM 提供商/模型/API Key、命名规则、主题 |

## 3. 核心流程

### 3.1 典型用户流程一：批量整理扫描件

```mermaid
flowchart LR
    A["启动应用"] --> B["选择本地工作目录"]
    B --> C["拖拽扫描图片到工作台"]
    C --> D["一键：扫描件优化（纠偏/增强）"]
    D --> E["调用 AI 分析（OCR + LLM）"]
    E --> F["显示建议的文件名与分类"]
    F --> G["用户逐条确认或一键全部应用"]
    G --> H["文件自动重命名并移动到目标目录"]
    H --> I["可选：加入对应知识库"]
```

### 3.2 典型用户流程二：基于知识库检索与问答

```mermaid
flowchart LR
    A["进入知识库工作区"] --> B["选择/新建一个知识空间"]
    B --> C["批量导入文档（PDF/Word/图片）"]
    C --> D["后台：向量化 + 索引构建"]
    D --> E["用户输入关键词或自然语言问题"]
    E --> F["系统：混合检索 + LLM 生成答案"]
    F --> G["返回：答案摘要 + 相关文档高亮片段"]
```

### 3.3 典型用户流程三：日常文件整理

```mermaid
flowchart LR
    A["文件工作台"] --> B["选择杂乱文件夹"]
    B --> C["AI 分析目录结构与文件类型"]
    C --> D["输出整理建议（合并/拆分/重命名）"]
    D --> E["用户选择并执行"]
    E --> F["生成整理前后对比报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：深蓝灰 `#1e293b`（专业、沉稳），点缀色**青绿** `#0d9488`（科技、智能）
- **辅助色**：琥珀色 `#f59e0b`（告警/待确认），淡青蓝 `#e0f2fe`（信息区背景）
- **字体**：中文使用 **"思源黑体 / Noto Sans SC"**，英文使用 **"Inter"**（但实际渲染采用系统字体栈，避免加载依赖）
- **字体层级**：标题 22–28px / 子标题 16–18px / 正文 14px / 辅助 12px
- **按钮风格**：圆角 8–12px，实心主按钮 + 描边次按钮，hover 有轻微抬升与阴影
- **布局风格**：三栏式（左侧导航 + 中间主内容 + 右侧 AI 建议面板）
- **图标**：`lucide-react` 线性图标，保持统一 1.25px 线宽
- **动效**：柔和过渡（150–250ms），AI 区域使用呼吸光晕与渐入动画，避免过度动画

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
| --- | --- | --- |
| 首页仪表盘 | 概览卡片 + 快捷入口 | 数据卡片网格、AI 图标、渐入动画、深色/浅色切换 |
| 文件工作台 | 目录树 + 文件列表/网格 | 可折叠目录树、拖拽区、进度条、选中态高亮 |
| 扫描件处理 | 双栏：图片 + 工具栏 | Canvas 预览、旋转/纠偏/裁切滑块、批量队列 |
| AI 智能命名分类 | 主表格 + AI 面板 | 原始文件名 / 建议文件名 / 建议分类 / 状态标签 / 批量确认按钮 |
| 知识库 | 空间卡片 + 问答 | 搜索框、流式输出的对话气泡、引用来源卡片 |
| 系统设置 | 分区 Tab | 分组表单、密钥输入（密码框）、保存后 toast 反馈 |

### 4.3 响应式

- **桌面优先**（≥ 1280px）：三栏布局，面向 14–27 寸显示器
- **中屏**（1024–1279px）：右侧 AI 面板可折叠
- **小屏**（< 1024px）：简化为两栏，AI 面板通过底部抽屉呼出（本产品 MVP 以桌面为主，移动端为降级支持）

## 6. 非功能需求

- **性能**：单目录 ≤ 10,000 文件时 UI 响应 < 1s；AI 调用流式返回首字节 ≤ 2s
- **离线可用**：文件管理与扫描件处理完全本地；AI 功能需要网络但具备 Mock 模式
- **数据安全**：API Key 加密存储在本地配置文件，不在前端日志或界面明文显示；不上传用户文档到非用户指定的第三方
- **可移植性**：配置与知识库索引可整体迁移
- **可维护性**：模块化分层架构，核心 AI 接口抽象（OpenAI-compatible 即可切换多家 LLM）
